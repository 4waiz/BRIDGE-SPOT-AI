🤖 Spot Voice Assistant Test

Interactive voice-controlled AI assistant

📋 How to Use

  1. Click the "Launch Voice Assistant" button above
  2. Allow microphone access when prompted
  3. Say "Hey Spot" to activate
  4. Wait for Spot to respond "Hey there! How may I help you?"
  5. Ask your question naturally
  6. Spot will respond with voice and text
⚠️ Note: This feature requires a modern browser with Web Speech API support (Chrome, Edge, or Safari recommended). Please allow microphone access when prompted.

💡 Sample Questions to Try

  • What can you do?
  • Tell me about Spot
  • What is Boston Dynamics?
  • Can you climb stairs?
  • How fast can you move?

  • What is HSSE?
